### Golden Set 机制（已建成）

- **用例结构**：`expected.json`（人工标注预期差异）+ `actual.json`（系统实际输出），支持三轮审核（APPROVED / DRAFT / REJECTED）。
- **回归流程**：`QualityWorkbench` 支持一键运行回归 → 自动计算 Precision / Recall / Known-False-Positive → 门禁判定（threshold_failures）。
- **扩增方式**：通过 Quality Workbench 前端 `导出 Draft Golden Set` 按钮，可将任意历史任务转为黄金用例；支持 `补录漏报` 录入漏检差异。
- **覆盖场景**：
  - ✅ 扫描版合同（通过 PP-Structure OCR 混合链路处理）
  - ✅ 长篇合同（流水线支持跨页条款延续合并、页眉页脚排除）
  - ✅ 表格密集（table_compare 子系统 10 个模块：解析/匹配/差异构建/修复/结构修复/HTML解析/bbox网格/汇总）
  - ✅ 盖章签署页（signing_region 子系统：规则检测 + OpenCV 视觉检测 + 混合融合 + 指纹匹配）
  - ✅ 附件页（appendix_section_flow 测试覆盖、条款拆分支持层级路径标注）

### 2.1 差异识别准确性

**当前流水线处理能力（基于最新任务 c265a5b1 的实测数据）：**

| 指标 | 数值 | 说明 |

**质量评估体系（Quality Attribution）：**

每个差异均附带质量属性标签：
- `CRITICAL_VALUE_CHANGE` — 关键数值变更（金额、日期、编号）
- `NEEDS_REVIEW` — 标记需人工复核
- 低置信 OCR / 页面不可靠 / 表格识别风险 / 版面匹配风险 / 阅读顺序风险 / 签章识别风险 / 证据不可靠
- OCR 处置状态：需人工处置 / 处置规划 / 已自动处置 / 处置未完成

### 2.2 误报控制

**已实施的误报抑制策略（June 23 - July 9）：**

| 策略 | 实现模块 | 效果 |

### 2.3 原文定位效果

**证据定位链路：**

```
DiffItem → EvidenceLocator（精确文本匹配 → Block 回退 → Clause 回退）→ EvidenceBBox[]
```

- 精确文本匹配优先：在原文页面 Block 中搜索差异文本的精确位置。
- Block 级别回退：精确匹配失败时，使用所属条款的 Block 坐标。
- Clause 级别回退：Block 定位也失败时，使用整个条款的坐标范围。
- 可视化验证：`EvidenceLocator` + `PdfHighlighter` 将坐标生成 SVG 覆盖层，渲染在 PDF 页面上。
- 调试产物：`tmp/task_434_visual_audit/` 包含实际的页面渲染 + 高亮叠加图，可用于人工验证定位准确性。

## 4. 前端查看体验优化

### 4.1 差异高亮（已完成）

- **颜色编码**：ADD（绿）、DELETE（红）、MODIFY（橙），与正文/签章/结构三个区域分别渲染。
- **SVG 精确覆盖**：`PdfHighlightLayer` 组件根据后端返回的 EvidenceBBox 坐标，在 PDF canvas 上方叠加 SVG 矩形高亮层。
- **同类型合并**：相邻的同一差异同类型高亮矩形自动合并，减少视觉碎片。
- **激活态/非激活态**：当前聚焦的差异高亮为完整不透明色，其他差异为半透明弱化（muted），对比鲜明。

### 4.2 问题定位跳转（已完成）

- **比对轴（Comparison Axis）**：两个 PDF 面板之间的垂直导航条，每个差异一个可点击标记点。
  - 标记位置根据 `(pageNo, y0)` 坐标计算，带碰撞避让（collision avoidance spacing）。
  - 点击标记 → 两个 PDF 同时滚动到对应页面和位置。
- **双向联动**：
  - 点击 PDF 页面上的 SVG 高亮 → 激活对应差异 → 侧边栏审计卡片自动选中。
  - 点击侧边栏审计卡片 → PDF 滚动到对应差异位置。
  - 同一差异的左右两页（原文/对比）同步高亮。

### 4.3 风险项独立查看（已完成）

- **分组展示**：审计面板按四个类别分组：MAIN（正文差异）、SIGNING（签章区差异）、STRUCTURAL（结构与质量提示）、OTHER（其他差异）。
- **优先级排序**：CRITICAL_VALUE_CHANGE 在 MAIN 中置顶 → MAIN → SIGNING → STRUCTURAL → OTHER。
- **质量标签体系**：每张审计卡片携带多维质量标签：
  - "关键差异"（金额/日期/编号变动）
  - "待复核"（置信度不足，需人工判断）
  - OCR 质量风险标签（低置信/页面不可靠）
  - 表格/版面/签章/阅读顺序风险标签
  - OCR 处置状态标签（需人工处置/已自动处置/处置未完成）
- **复核操作**：每张卡片提供"忽略"/"恢复"按钮，状态在 UNREVIEWED / CONFIRMED / FALSE_POSITIVE / IGNORED 之间切换，结果持久化到后端。

### 4.4 其他前端优化（已完成）

## 6. 用户使用说明

### 合同对比系统 — 操作指南

---

#### 步骤一：上传合同

1. 打开系统首页（上传页面）。
2. 点击 **"原始合同"** 区域，选择待审查的合同 PDF 文件（如：供应商发来的合同）。
3. 点击 **"对比合同"** 区域，选择用于对比的合同 PDF 文件（如：公司标准模板或历史版本）。
4. **可选设置**：
   - **忽略签章**：勾选后，签章区域（盖章、签名）的差异将归类至"签章区差异"而非正文差异。
   - **排除页眉页脚**：勾选后，页眉页脚的合同编号、页码等变化不会被标记为差异。
   - **签章区域检测模式**：选择"规则检测"（默认，基于关键词匹配）或"混合检测"（规则 + 视觉识别，适合扫描件）。
5. 点击 **"开始对比"** 按钮，系统开始处理。

> ⏱️ 处理时间取决于合同页数、是否扫描件、OCR 引擎负载，通常 30 秒到 3 分钟。

---

#### 步骤二：查看结果

处理完成后自动跳转至结果页面。结果页面由三个区域组成：

**左侧区域 — 原始合同 PDF 查看器：**
- 显示原始合同，差异位置以对应颜色高亮（绿色=新增、红色=删除、橙色=修改）。
- 支持缩放（50%-160%）、上下滚动浏览。

**中间区域 — 对比合同 PDF 查看器 + 比对轴：**
- 显示对比合同，与左侧同步滚动（可通过开关关闭同步）。
- 两个查看器之间的竖条为 **比对轴**（Comparison Axis），每个色块代表一处差异，色块在轴上的位置对应差异在合同中的位置。
- 点击比对轴上的色块，左右两个 PDF 同时跳转到该差异所在页面。

**右侧区域 — 审计面板（差异清单）：**
- 差异按以下分组排列：
  - **正文差异**：合同主体内容的增删改。
  - **签章区差异**：盖章、签名区域的差异（如忽略签章则在此显示）。
  - **结构与质量提示**：页眉页脚、排版、OCR 质量相关的提示。
  - **其他差异**：不在以上分类的杂项差异。
- 关键差异（如金额、日期、编号变动）会置顶并标注 **"关键差异"** 标签。
- 携带风险标签的差异会显示对应警告标识（如"待复核"、"低置信 OCR"）。

---

#### 步骤三：复核问题

1. **逐条审查**：在审计面板中逐条点击差异卡片，PDF 会自动跳转到对应位置。
2. **判断差异**：
   - 确认真实差异 → 无需操作，状态保持为"未复核"或标记为"已确认"。
   - 确认误报 → 点击卡片上的 **"忽略"** 按钮，该差异状态变为"已忽略"，颜色变灰。
   - 误操作 → 点击 **"恢复"** 按钮，将已忽略的差异恢复。
3. **筛选差异类型**：使用面板顶部的筛选按钮（全部 / 新增 / 删除 / 修改）缩小关注范围。
4. **批量导出**：确认无误后，点击页面底部的 **"下载报告"** 按钮获取对比报告 PDF。

> 💡 建议优先处理标记为"关键差异"和"待复核"的条目，这些是最可能需要关注的变更。

---

#### 步骤四：导出报告

1. 在结果页面底部或顶部工具栏，找到下载按钮组：
   - **下载原始合同**：下载上传的原始合同 PDF。
   - **下载对比合同**：下载上传的对比合同 PDF。
   - **下载对比报告**：下载系统生成的差异审查报告 PDF。
2. 对比报告 PDF 包含：
   - 合同基本信息（文件名、页数、对比时间）。
   - 差异汇总表（总数、各类型数量）。
   - 每处差异的详情（位置、类型、原文片段 vs 对比片段）。
   - OCR 质量摘要。
3. 报告可用于内部审批、归档或发送给合同对方。
