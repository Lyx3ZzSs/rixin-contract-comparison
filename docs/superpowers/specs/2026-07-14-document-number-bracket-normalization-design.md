# 公文号括号 OCR 变体归一化

## 背景

任务 `75d70af0-51e6-4436-833d-f9f71d6d60d9` 的 PDF 第 44 页（页码标注为 43）中，原件 OCR 将 `〔2006〕34` 识别为 `（2006）34`，而对比件识别为 `〔2006〕34`。两份原始 PDF 的实际内容一致，但当前差异归一化未将 `〔〕` 视为公文号年份括号的等价写法，产生了 `MODIFY` 误报。

## 决策

在 `TextNormalizer` 的匹配和差异归一化路径中，仅规范化“年份位于成对括号中”的公文号形式：`(YYYY)`、`（YYYY）` 与 `〔YYYY〕` 具有相同的比较语义。显示文本和其他用途的 `〔〕` 不改变。

## 范围与行为

- `会电监安全（2006）34号` 与 `会电监安全〔2006〕34号` 不生成条款差异。
- 年份或编号本身发生变化时仍生成差异，例如 `〔2006〕34号` 与 `〔2007〕34号`。
- 不重写 OCR 源文本、不修改既有任务产物，也不改变非年份括号的语义。

## 验证

在现有文本清洗质量测试中先新增失败用例，覆盖归一化等价性、条款差异抑制和真实年份变化；随后以最小实现使测试通过，并运行相关测试、后端完整测试及 lint。
