## 已清理

| 项目 | 处理 |
|---|---|

| 匹配结束后无条件构建结果映射 | 仅在试验策略启用且实际选择了快速候选时构建，用于检测分配冲突和回退。 |
| embedding 循环重复读取去重开关 | 每批读取一次；唯一文本统计仍用于性能指标。 |
| 旧提取缓存死代码 | 删除 `if False` 分支、唯一被该分支引用的指纹函数及过时说明；活动后端中已无这些残留引用。 |
| 图形比较器的多余工厂别名 | 删除实例上的 `_cache_factory`，直接创建已有的 `PageRenderCache`。 |
| 两个基准脚本重复实现 | 公共配置初始化、服务构建、输入查找、代码哈希、结果写入、HTTP 捕获/回放及失败统计归入 `benchmark_support.py`。两个入口继续负责各自的单任务回放和队列并发场景。 |
| 一次性调度脚本 | 删除已经运行完毕、硬编码旧输出目录的 `run-final-runtime.py`；保留冻结基线、原始结果与可复现组件探针。 |

公共 HTTP 记录器使用上下文管理，结束或异常时恢复原客户端方法；保留错误响应和缓存缺失的区别。并发基准只统计成功任务吞吐。单任务驱动提交异常时也会停止队列和内存采样线程。

有效的页面/条款特征缓存、图像缓存、试验开关、分配冲突回退及页面路由回退仍保留，默认配置未改变。此次未修改 Golden 真值，也未部署。
