# 质量工作台退役说明

质量工作台已从线上产品中硬下线。前端不再提供 `/quality/workbench` 页面，后端不再注册
`/api/quality/*`，旧地址分别按未知前端路由回到首页或返回 HTTP 404。

本次退役同时移除了线上案例目录、运行目录、镜像种子初始化和对应 Docker 配置。部署升级不会主动
删除已有外部持久卷中的质量数据；如确认不再需要，应由运维按实际卷名独立归档或清理。

生产对比链路中的 OCR 质量评估、OCR 风险处置、差异去重与噪声过滤均予以保留。
`/api/compare/*` 的质量摘要、复核标记、证据与历史任务字段继续兼容。

Golden Set、质量评估脚本、回归脚本和脱敏测试夹具仍保留，但仅用于本地开发和自动化测试。
相关操作参见 `docs/golden_set_regression_sop.md`。
